# Meetup Transcribe & Diarization with pyannote & Groq

Автоматизированный инструмент и AI-скилл для **автоматического поиска и расшифровки аудиозаписей рабочих встреч**, **диаризации и распознавания реальных имён спикеров** (с помощью `pyannote.audio` и Groq LLM), **ведение реестра всех исходников и результатов** и **создания фоллоу-апов созвонов** в чистом текстовом формате без разметки Markdown.

---

## 🎯 Ключевые возможности

- 📁 **Автоматический отбор и Реестр**: Сканирование папки `audio/`, определение непереработанных встреч и ведение единого реестра в `реестр.md` с ссылками на исходники и результаты.
- ⚡ **Высокоскоростное распознавание и авто-нарезка**: Поддержка файлов любого размера (>24 МБ) благодаря авто-разбиению через `ffmpeg` и Groq API.
- 🔄 **Автоматическое переключение моделей (Model Fallback)**: Воспроизведение начинается на основной модели `whisper-large-v3`. Если у аккаунта исчерпывается часовой лимит или закончились кредиты (`HTTP 429` / `rate_limit_exceeded`), систему не ломает: происходящий авто-перехват мгновенно переключает текущий и последующие чанки на запасную модель **`whisper-large-v3-turbo`**.
- 🗣 **Диаризация и Идентификация спикеров**: 
  - Диаризация голосов через нейросеть `pyannote.audio`.
  - Автоматическое определение **реальных имён участников** (например, *«Альмир»*, *«Оскар Хартманн»*) с помощью Groq LLM (`llama-3.3-70b-versatile`) и замена безымянных меток в JSON-транскрипте.
- 📋 **Строго чистый текстовый отчет**: Генерация результатов в формате `txt` (без разметки Markdown `#`, `**`, `*`), полностью соответствующая протоколу встреч по шаблону `examples/example.md`.
- 🤖 **Полная интеграция с AI-агентами**: Готовая спецификация `SKILL.md` для работы в Antigravity, Claude Code и других агентских средах.

## 📦 Быстрый старт

### 1. Клонирование и установка зависимостей

```bash
git clone https://github.com/Asmadey/meetup-diarization-with-pyannote.git
cd meetup-diarization-with-pyannote

# Создание и активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

> **Примечание:** На компьютере должен быть установлен `ffmpeg` (на macOS: `brew install ffmpeg`).

---

### 🔑 2. Настройка ключей доступа (`.env`)

Создайте файл `.env` на основе шаблона `.env.example`:

```bash
cp .env.example .env
```

Заполните переменные в `.env`:

```env
# API Ключ Groq (получить на https://console.groq.com)
GROQ_API_KEY=gsk_your_groq_api_key

# Access Token Hugging Face (получить на https://huggingface.co/settings/tokens)
HF_TOKEN=hf_your_huggingface_token
```

#### Как получить токен Hugging Face для pyannote.audio:
1. Зарегистрируйтесь или войдите на [huggingface.co](https://huggingface.co).
2. Подтвердите бесплатное лицензионное соглашение на страницах **трех** моделей (на каждой странице нажмите кнопку **«Agree and accept conditions»**):
   - 👉 [pyannote/speaker-diarization-3.1](https://huggingface.co/pyannote/speaker-diarization-3.1)
   - 👉 [pyannote/segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0)
   - 👉 [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1)
3. Создайте токен с правами `Read` на странице [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) и скопируйте его в `.env`.

## 🚀 Использование

### ⚡ Один запуск для полной обработки (Рекомендуется)

Положите файл с аудиозаписью встречи в папку `audio/` и запустите автоматический конвейер:

```bash
python3 scripts/process_latest.py
```

Скрипт автоматически:
1. Найдет последний непереработанный файл в `audio/`.
2. Выполнит транскрибацию через `whisper-large-v3` (с автоматическим фолбэком на `whisper-large-v3-turbo` при превышении лимитов).
3. Определит имена спикеров и заменит `SPEAKER_UNKNOWN` на реальные имена участников в JSON.
4. Создаст фоллоу-ап в `followups/`.
5. Запишет информацию и прямые ссылки на все файлы в `реестр.md`.

Вы также можете запустить обработку конкретного файла вручную:
```bash
python3 scripts/process_latest.py --audio audio/meet.m4a --title "Синк по направлению Recsys — 30.07.2026"
```

---

### 🔨 Пошаговый запуск отдельных модулей

Если вам требуется запустить этапы по отдельности:

```bash
# 1. Транскрибация и диаризация (авто-фолбэк включен по умолчанию)
python3 scripts/transcribe_diarize.py --audio audio/meet.m4a --output transcripts/meet.json

# 2. Определение имен спикеров через LLM
python3 scripts/resolve_speakers.py --input transcripts/meet.json

# 3. Построение фоллоу-апа без Markdown
python3 scripts/format_followup.py --input transcripts/meet.json --title "Синк по продукту — 30.07.2026" --output followups/meet.txt
```
